## Почему Mac Sai?

Полноценный инструмент для очистки Mac не должен стоить годовой подписки и не должен просить вас доверять «чёрному ящику» с глубоким доступом к вашим файлам. Mac Sai даёт весь набор инструментов, полностью открыто.

- **Бесплатно, навсегда.** Без подписки, без встроенных покупок, без «перейдите на Pro», без навязчивых окон. Лицензия BSD-3.
- **Ноль телеметрии.** Нет аналитики, нет отчётов о сбоях, нет трекеров, нет сервера, куда можно было бы что-то отправить. И не нужно верить на слово: вы можете [проверить это сами](#проверьте-отсутствие-телеметрии-сами) двумя командами.
- **Все ключевые инструменты CleanMyMac в одном приложении.** 22 модуля для очистки, защиты, производительности, управления приложениями и анализа диска, плюс виджет в строке меню.
- **Безопасность по умолчанию.** Удаление сначала в Корзину, чёрный список защищённых путей, защита от символьных ссылок и TOCTOU, и `SafetyGuard`, который проверяет каждый путь. Приложение спроектировано так, чтобы никогда не терять ваши данные.
- **Заверено Apple и полностью открыто.** Ваш Mac проверяет подпись при каждом запуске, а каждая строка кода доступна для чтения.

## Возможности подробно

### 🧹 Очистка
| Модуль | Что делает |
|--------|------------|
| **Умное сканирование** | Один клик запускает модули очистки, защиты и производительности сразу, с прогрессом в реальном времени, и показывает, сколько именно освобождено по каждому модулю |
| **Системный мусор** | 16+ категорий сканирования: пользовательские и системные кэши, журналы, языковые файлы, повреждённые настройки, повреждённые объекты входа, версии документов, резервные копии iOS, мусор Xcode, кэши менеджеров пакетов / IDE / ИИ-инструментов, остатки удалённых пользователей, а также **прореживание Universal Binary** (находит толстые Mach-O с срезами arm64 и x86_64 и переписывает их под вашу архитектуру через `lipo`, с поддержкой отмены) |
| **Вложения почты** | Находит кэшированные вложения из Apple Mail, Outlook и Spark |
| **Корзины** | Очищает Корзину во всех местах, включая внешние диски |
| **Мусор проектов** | Находит воссоздаваемые папки сборки в ваших проектах: `node_modules`, `.next`, `dist`, `target` для Rust и Maven, `build` для Gradle, виртуальные окружения Python и `Pods` для CocoaPods. Папка учитывается, только если соседние файлы подтверждают тип проекта, а `dist` и `Pods` только если они указаны в вашем `.gitignore`. Всё перемещается в Корзину |
| **Дисковые «пожиратели»** | Показывает, сколько места занимают Docker и симуляторы Xcode. Удаляет остановленные контейнеры, висячие образы и висячий кэш сборки (каждое после подтверждения), а также недоступные симуляторы и старые среды выполнения симуляторов. Тома Docker и самая новая среда выполнения для каждой платформы никогда не затрагиваются |
| **История очистки** | Показывает ваши недавние очистки (за последние 30 дней, до 20) и возвращает целую очистку из Корзины одним щелчком. История хранится только на вашем Mac в `~/Library/Logs/MacClean/clean-history.json`, доступна для чтения только вашей учётной записи и никуда не отправляется |

### 🛡️ Защита
| Модуль | Что делает |
|--------|------------|
| **Удаление вредоносных программ** | Сигнатурное сканирование с 3 уровнями глубины (Быстрый / Сбалансированный / Глубокий): агенты и демоны запуска, пакеты приложений, расширения браузеров и известные шаблоны рекламного/вредоносного ПО. Точная сверка хешей с сигнатурами Apple XProtect, которые уже есть на вашем Mac, без сети, а также необязательная лента хешей MalwareBazaar (abuse.ch). Расширения Safari из чёрного списка Apple и совпадения с MalwareBazaar показываются для проверки и никогда не отмечаются заранее (это не антивирус, и мы так и говорим) |
| **Конфиденциальность** | Очищает историю, cookie и кэш Safari, Chrome и Firefox, с фильтрами по времени. Закладки Safari **никогда не затрагиваются** |
| **Расширения браузеров** | Показывает расширения, установленные в Safari, Chrome, Brave, Edge, Arc и Firefox. Расширения Chromium и Firefox, установленные вами, можно переместить в Корзину, пока браузер закрыт; установленные политикой или самим браузером показываются, но не трогаются. Для расширений Safari открываются настройки Safari |
| **Сохранённые сети Wi-Fi** | Показывает список предпочитаемых беспроводных сетей и забывает выбранные вами |
| **Обзор разрешений** | Только для чтения: обзор по приложениям, какие разрешения приватности (TCC) есть у каждого приложения, тот ракурс, которого не даёт «Системные настройки». Любое действие ведёт в «Системные настройки», где и находятся сами переключатели |

### ⚡ Производительность
| Модуль | Что делает |
|--------|------------|
| **Оптимизация** | Управление объектами входа и агентами запуска с включением/выключением каждого |
| **Обслуживание** | Системные задачи: освободить память, запустить скрипты обслуживания, проверить загрузочный диск, перестроить Launch Services, переиндексировать Spotlight, сбросить DNS, проредить локальные снимки Time Machine. Задачи помечены по уровню риска, «Запустить безопасные задачи» выполняется последовательно, а пароль администратора запрашивается **один раз** |

### 📦 Приложения
| Модуль | Что делает |
|--------|------------|
| **Удаление приложений** | Движок сопоставления, который находит каждый связанный файл в 17+ подкаталогах Library (включая приложения во вложенных папках вендоров). Полное удаление, **сброс к настройкам по умолчанию** (очистка кэшей и настроек приложения с сохранением самого приложения) и обнаружение неиспользуемых приложений |
| **Неиспользуемые приложения** | Находит приложения, которые вы не открывали 3, 6 или 12 месяцев, по дате последнего использования из Spotlight, с сортировкой по размеру. Запущенные приложения никогда не попадают в список, а если у Spotlight нет данных об использовании, модуль так и сообщает, а не гадает. Один щелчок передаёт приложение в модуль удаления |
| **Расширения** | Просмотр сторонних панелей настроек, интернет-плагинов и расширений Safari. Установленные пользователем панели и плагины можно переместить в Корзину |
| **Обновления приложений** | Проверяет обновления установленных приложений по их собственным лентам Sparkle (читает только сведения о версии и не отправляет ничего о вас) |

### 🗂️ Файлы
| Модуль | Что делает |
|--------|------------|
| **Space Lens** | Визуализация занятости диска квадрифицированной картой с возможностью углубляться по папкам |
| **Большие и старые файлы** | Находит файлы больше 50 МБ, сортирует по размеру и дате последнего доступа |
| **Дубликаты** | Поэтапное обнаружение (группировка по размеру, частичный SHA-256, полный хеш, проверка inode), плюс режим **объединения**, который освобождает место клонами APFS с копированием при записи, не удаляя ни одной копии |
| **Шреддер** | Безопасное стирание файлов в стандартном, необратимом и режиме безопасной перезаписи |

### 📊 Виджет в строке меню

<p align="center">
  <img src="assets/menu_bar.png" width="300" alt="Виджет Mac Sai в строке меню" />
</p>

Виджет в строке меню в стиле «матового стекла», который держит показатели вашего Mac в одном клике. Это отдельный процесс, запускается при входе и включается из боковой панели приложения, так что открывать главное окно ради быстрой проверки не нужно.

- **Живые кольца показателей**: загрузка CPU, давление памяти, занятость диска и батарея в сетке 2x2 (`host_processor_info`, `vm_statistics64`, ёмкость APFS, источник питания IOKit), с градацией цвета от зелёного к янтарному и красному
- **Настраиваемый показатель**: свободное место, загрузка GPU, использование памяти или температура батареи; выбор сохраняется, недоступные датчики показывают `--`
- **Сеть, время работы и подкачка**: скорость приёма/передачи в реальном времени, время работы системы, использование подкачки
- **Рекомендации**: полезные подсказки, которые можно закрыть («Пользовательские кэши выросли до 2.52 ГБ, запустите Системный мусор»), одно нажатие для действия, скрываются на 30 дней после закрытия
- **Статус защиты**: время последнего сканирования на вредоносное ПО и число угроз, с цветовой пометкой по свежести
- **Подключённые устройства**: внешние тома (со свободным местом) и дисплеи с первого взгляда
- **Оповещения о состоянии**: уведомления (с ограничением частоты, по желанию), когда на диске критически мало места или давление памяти долго держится высоким

## Установка

### Homebrew (рекомендуется)

Mac Sai есть в официальном Homebrew cask, tap не нужен:

```bash
brew install --cask mac-sai
```

Приложение заверено Apple, поэтому запускается из Spotlight или «Программ» без предупреждений и лишних шагов.

<details>
<summary><strong>Другие способы установки</strong> (скрипт в одну строку, DMG, сборка из исходников)</summary>

<br>

**Установщик в одну строку**

```bash
curl -fsSL https://raw.githubusercontent.com/iliyami/MacSai/main/scripts/install.sh | bash
```

Скачивает последний DMG и устанавливает приложение в `/Applications`.

**Скачивание DMG**

Возьмите последний DMG со страницы [Releases](https://github.com/iliyami/MacSai/releases/latest) и перетащите Mac Sai в папку «Программы».

**Сборка из исходников**

```bash
git clone https://github.com/iliyami/MacSai.git
cd MacSai
swift build
swift test                     # запустить весь набор из 1048 тестов
bash scripts/build-dmg.sh      # собрать локальный DMG (без подписи)
```

Требуется тулчейн Swift 6 (Xcode 16+).

**Устанавливали через старый tap?**

Теперь Mac Sai в официальном cask, так что tap можно убрать: `brew untap iliyami/macsai` (на установленное приложение и будущие `brew upgrade` это не влияет).

</details>

### Полный доступ к диску

Нескольким модулям (Вложения почты, Конфиденциальность, Вредоносное ПО) нужен полный доступ к диску для сканирования защищённых областей:

1. Откройте **Системные настройки, Конфиденциальность и безопасность, Полный доступ к диску**
2. Нажмите **+** и добавьте **Mac Sai.app**
3. Перезапустите Mac Sai

### Удаление

Установка через Homebrew:

```bash
brew uninstall --zap --cask mac-sai
```

Установка через DMG или вручную (также обрабатывает установку через Homebrew):

```bash
curl -fsSL https://raw.githubusercontent.com/iliyami/MacSai/main/scripts/uninstall.sh | bash
```

Оба варианта удаляют Mac Sai вместе с его настройками, кэшами, журналами и базой данных в `~/Library`.

## Подписано, заверено Apple и заслуживает доверия

Mac Sai подписан идентификатором Apple **Developer ID** и **заверен Apple**. Для приложения-очистителя это важнее, чем почти для всего остального, что вы устанавливаете, ведь вы вот-вот дадите ему глубокий доступ к своим файлам, и вы вправе знать, что на вашем Mac работает действительно наша и неизменённая сборка. Всё это обеспечивает ваш собственный Mac, а не только наши обещания:

- **Apple его проверила.** Каждый релиз отправляется в Apple и проверяется на вредоносное ПО перед выпуском.
- **Его нельзя подменить.** Подпись это криптографическая печать над каждым файлом; измените хоть один байт, и macOS откажется его открыть.
- **Он доказуемо от нас.** Подпись привязана к нашему идентификатору разработчика Apple, поэтому никто другой не выпустит то, что ваш Mac примет за Mac Sai.
- **Просто работает.** Без предупреждений Gatekeeper, без открытия через правый клик, без Терминала.

Вместе с полностью открытым кодом это цепочка доверия, которую не нужно принимать на веру: код открыт, мы подписываем каждый релиз, Apple его проверяет, а ваш Mac перепроверяет печать при каждом открытии.

### Проверьте отсутствие телеметрии сами

Не верьте нам на слово. И исходный код, и работающий процесс можно проверить.

**1. Поиск сетевых API в исходниках**

```bash
rg -n 'URLSession|NSURLConnection|Sparkle|SecTrustEvaluate' Sources --glob '*.swift'
```

Необязательные сетевые обращения перечислены ниже. Локальная очистка не передаёт результаты сканирования или списки файлов:

- `Sources/MacClean/Services/SelfUpdateController.swift`: Sparkle проверяет HTTPS-ленту, указанную в подписанном приложении, и загружает подписанные описания и архивы обновлений. Автоматическая проверка и автоматическая загрузка с установкой включаются отдельно; отправка системного профиля и JavaScript в описаниях отключены. См. [настройку обновлений](docs/IN_APP_UPDATES.md). В настроенных сборках для прямой установки автоматическая проверка обновлений включена по умолчанию и выполняется раз в сутки; каждый запрос содержит версии приложения и Sparkle в User-Agent, а проверки можно отключить в Настройках.
- `Sources/MacCleanKit/UpdateChecker.swift`: проверка обновлений Homebrew и переход на страницу релизов в сборках без настроенной подписанной ленты
- `Sources/MacClean/Modules/Updater/UpdaterModule.swift`: запускаемая пользователем проверка лент Sparkle *других приложений* при открытии модуля «Обновления»
- `Sources/MacCleanKit/MalwareBazaarFeed.swift`: необязательная загрузка хешей MalwareBazaar. Она выполняется, только если вы добавили собственный Auth-Key abuse.ch и нажали «Обновить сейчас» в разделе «Настройки» > «Базы вредоносного ПО». Каждый запрос передаёт только ваш Auth-Key и сам запрос, но никогда не хеши файлов и не пути. Если загруженный хеш совпадает с подписанным файлом, macOS запрашивает у Apple, не отозван ли его сертификат подписи (та же проверка, что и у Gatekeeper); этот запрос касается сертификата, а не ваших файлов

В коде нет никакой аналитики, отчётов о сбоях или трекеров.

**2. Наблюдение за живым процессом**

```bash
(
MACSAI_APP=$(cd "/Applications/Mac Sai.app" && pwd -P) || exit 1
MACSAI_PIDS=$(ps -ww -axo pid=,comm= | awk -v bundle="$MACSAI_APP/" '
  { pid=$1; sub(/^[[:space:]]*[0-9]+[[:space:]]+/, "")
    if (index($0, bundle) == 1) print pid }' | paste -sd, -)
if [ -n "$MACSAI_PIDS" ]; then
  ps -p "$MACSAI_PIDS" -o pid=,comm=
  lsof -nP -a -p "$MACSAI_PIDS" -i
else
  echo "No running executables from this Mac Sai bundle"
fi
)
```

Этот снимок выбирает PID по путям исполняемых файлов внутри указанного приложения, поэтому посторонние процессы Installer/Updater не попадают в выборку. Помощники Sparkle, скопированные в другие каталоги, и системные службы доверия macOS находятся за её пределами; для них используйте межсетевой экран с учётом процессов. Повторяйте команду во время проверки или загрузки обновления, чтобы увидеть короткие соединения.

Если проверка и загрузка обновлений, а также необязательная проверка вредоносного ПО не выполняются, локальная очистка не открывает сетевые соединения. При обновлении учитывайте дочерние процессы Sparkle; проверка сертификатов Apple выполняется системными службами доверия macOS. Соединения также можно наблюдать в Little Snitch или LuLu.

**3. Проверьте бинарник, который вы на самом деле установили**

Для установки из DMG или Homebrew достаточно средств командной строки macOS; исходники и Python не нужны. Этот цикл читает все семь бинарных компонентов и выводит распространённые сетевые импорты, статические URL и строки трекеров для ручной проверки:

```bash
(
MACSAI_APP="/Applications/Mac Sai.app"
MACSAI_SPARKLE="$MACSAI_APP/Contents/Frameworks/Sparkle.framework/Versions/B"
for MACSAI_BINARY in \
  "$MACSAI_APP/Contents/MacOS/MacClean" \
  "$MACSAI_APP/Contents/Library/LoginItems/MacCleanMenu.app/Contents/MacOS/MacCleanMenu" \
  "$MACSAI_SPARKLE/Sparkle" "$MACSAI_SPARKLE/Autoupdate" \
  "$MACSAI_SPARKLE/Updater.app/Contents/MacOS/Updater" \
  "$MACSAI_SPARKLE/XPCServices/Downloader.xpc/Contents/MacOS/Downloader" \
  "$MACSAI_SPARKLE/XPCServices/Installer.xpc/Contents/MacOS/Installer"
do
  printf '\n%s\n' "$MACSAI_BINARY"
  MACSAI_IMPORTS=$(nm -uj "$MACSAI_BINARY") || exit 1
  printf '%s\n' "$MACSAI_IMPORTS" | grep -Ei \
    'URLSession|URLConnection|CFNetwork|Network|nw_|DNSService|NetService|curl_|^_(socket|connect|connectx|send|recv)([$]|$)' || true
  MACSAI_STRINGS=$(strings -a "$MACSAI_BINARY") || exit 1
  printf '%s\n' "$MACSAI_STRINGS" | grep -Ei \
    '://|sentry|firebase|mixpanel|amplitude|bugsnag|crashlytics|posthog|appsflyer' || true
done
)
```

Этот вывод не является автоматическим заключением об успешной проверке и не гарантирует видимость всех адресов, выбираемых во время работы. Для полной проверки состава, разрешённых списков и встроенных настроек конфиденциальности используйте скрипт ниже.

Запустите проверку из исходников, соответствующих установленной версии. Она анализирует приложение на диске: основной бинарник, помощник строки меню, `Sparkle.framework`, `Autoupdate`, `Updater.app`, `Downloader.xpc` и `Installer.xpc`:

```bash
bash scripts/check-network-surface.sh "/Applications/Mac Sai.app"
```

Ожидаемый результат: проверены семь файлов Mach-O. Отсутствующий или посторонний бинарник, сетевой импорт или статический URL вне разрешённого списка, а также признаки трекеров приводят к ошибке. Импорты URLSession разрешены в Mac Sai, его помощнике строки меню, Sparkle и Downloader; остальным помощникам Sparkle сетевые импорты не разрешены. Ссылки Sparkle на документацию и пространство имён XML перечислены отдельно и не считаются адресами загрузки.

Скрипт также выводит встроенный `SUFeedURL` и проверяет настройки подписанной ленты, проверки до распаковки и конфиденциальности. Сопоставьте адреса архивов и описаний в этой ленте, а также запрошенные вами ленты других приложений с живыми соединениями выше. Резервная проверка использует `api.github.com/repos/iliyami/MacSai/releases/latest` и `formulae.brew.sh/api/cask/mac-sai.json`; необязательная загрузка базы использует `mb-api.abuse.ch/api/v1/`. Ссылки проекта, поддержки и настроек браузера открываются по запросу пользователя. При упаковке выполняется та же проверка всего приложения; CI проверяет оба собранных бинарника и все пять бинарников закреплённой версии Sparkle. [Реализация и разрешённые списки](scripts/check-network-surface.py).

## Архитектура

```
Mac Sai
├── MacClean          Основное приложение SwiftUI (22 модуля)
├── MacCleanKit       Общий фреймворк (модели, константы, протоколы)
├── MacCleanHelper    Привилегированный помощник XPC (LaunchDaemon для root-операций)
└── MacCleanMenu      Монитор в строке меню (отдельный процесс)
```

### Технологии

| Слой | Технология |
|-------|-----------|
| Язык | Swift 6 со строгой конкурентностью |
| UI | Гибрид SwiftUI + AppKit |
| Конкурентность | Акторы, TaskGroup, async/await, `@Sendable` |
| База данных | GRDB.swift (SQLite) в режиме WAL |
| Сканирование файлов | Предвыборка `URLResourceKey` на APFS |
| Инкрементальные обновления | FSEvents с воспроизведением истории |
| Привилегированные операции | SMAppService + NSXPCConnection |
| Системная статистика | Mach API (`host_processor_info`, `vm_statistics64`, `proc_pidinfo`) |

### Модель безопасности

Mac Sai спроектирован так, чтобы **никогда не приводить к потере данных**:

- **Чёрный список защищённых путей**: `/System`, `/usr`, `/bin`, `/sbin` и системные приложения Apple неприкосновенны, а macOS firmlinks приводятся к канонической форме, чтобы обнаружение подмены символьных ссылок не срабатывало ложно на легитимных системных путях
- **Фильтр очищаемости перед сканированием**: объекты, которые текущий процесс не смог бы отправить в Корзину (root-владельцы внутри системных кэшей, каталоги под защитой data-vault в `~/Library/Caches/com.apple.*`), отбрасываются на этапе сканирования и никогда не показываются как «очищаемые»
- **Сначала в Корзину**: все удаления по умолчанию идут в Корзину, а режим пробного запуска показывает результат, ничего не трогая
- **Защита от TOCTOU**: символьные ссылки повторно разрешаются непосредственно перед удалением
- **Исключённые папки**: в настройках можно выбрать папки, которые сканирование полностью пропускает, и `SafetyGuard` дополнительно отказывается удалять что-либо внутри них
- **Пакетная, отменяемая очистка**: большие выборки разбиваются на пакеты по 5000 объектов с проверкой отмены между пакетами, а после нажатия «Отмена» сканирование возвращается в простой примерно за секунду
- **Журнал действий в приложении**: каждая ошибка при очистке записывается вместе с полным путём, доступна для просмотра и копирования на экране после очистки, записи старше 30 дней удаляются автоматически
- **Проверка XPC на уровне ядра**: привилегированный помощник использует `NSXPCListener.setCodeSigningRequirement`, так что само ядро отклоняет любое соединение, чья подпись кода не совпадает с идентификатором и командой основного приложения

## Тесты

```bash
swift test
```

Набор на основе XCTest содержит **1048 тестов** и относится к `SafetyGuard` и `CleaningEngine` (файлам жизни и смерти) как к обязанным быть безупречными: состязательное покрытие символьных ссылок, обхода путей, NULL-байтов, SIP, защищённых приложений, ограничений на число файлов, TOCTOU и идемпотентности, плюс интеграционное покрытие пробного запуска / удаления в Корзину / необратимого удаления, конечного автомата сканирования, каждой категории системного мусора, математики карты, движка сопоставления удаления, обнаружения дубликатов, разбора appcast и полных сквозных циклов «от синтетического стенда до очистки». Стенды (`withTempHome`, `withFakeApp`, `withFakePlist`) гарантируют, что ни один тест не касается вашей настоящей домашней папки.
